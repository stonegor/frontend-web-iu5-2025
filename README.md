# Разработка интернет-приложений (РИП) 2025

## Предсказание автора корпуса текста

Система позволяет пользователям отправлять на анализ текстовый корпус, предоставляя возможность быстро анализировать представленный материал, вычислять лингвистические метрики и сопоставлять их с базой данных известных авторов для определения наиболее вероятного автора.
